# Use cases

Examples that use several of the cancho tools **together** on a question someone would act on, each with a digital twin that generates
realistic fake data, so it runs anywhere with a known truth to check against. Unlike the programs in the folders above, these are
pipelines over the sibling tools (`table`, `stats`, `ml`, `solve`, `opt`, `flow`), not single cancho programs.

| Use case | Status |
|---|---|
| [`pharma-chain/`](pharma-chain/) | A pharmaceutical distribution chain seen from three places: pharmacy replenishment under expiry and cold chain, cold-chain delivery with electric trucks, and refill adherence. **Design only**: [`docs/use-cases.md`](../../docs/use-cases.md). No code yet. |

A use case gets a design section in `docs/` before any code is added here, and every claim in it is measured, read, a choice or open
(`CLAUDE.md`).
