# Brief: `count_words`

> `count_words(text)` answers how many words `text` has.
>
> A word is a run of bytes that are not blank. The blank bytes are space,
> tab and newline. The signature is

```
pub fn count_words[&r](text: &r [byte]) -> [] int
```

That is the whole brief. It is the brief the agent will get too -- plus
the contract you write.
